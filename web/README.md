# 포커페이스 웹앱 (PokerFace Web)

안드로이드 앱과 동일한 헤즈업 포커 어드바이저를, 별도 설치 없이 브라우저에서
바로 쓸 수 있게 만든 웹 버전입니다. Vite + TypeScript(프레임워크 없이 순수 DOM)로
작성했고, 포커 엔진(족보 판정·승률 계산·팟 오즈 추천)은 안드로이드 `core` 모듈의
Kotlin 로직을 TypeScript로 그대로 이식했습니다.

## 기능

- **홈** → **카드 설정**(스트리트 선택 + 카드 탭 선택) → **베팅 정보 입력** →
  **결과(추천 + 이유)** → **배우기** 흐름
- 몬테카를로 시뮬레이션으로 승률 추정(리버는 전수 계산), 팟 오즈와 비교해
  폴드/체크/콜/레이즈/올인 추천 + 한국어 설명
- **카메라 자동 인식**: 칸을 나누지 않고 화면 전체를 한 번에 촬영해, 브라우저
  OCR(Tesseract.js)로 보이는 카드 랭크를 모두 자동 추출합니다. 카드를 부채꼴로
  살짝 겹쳐 펼쳐 숫자 모서리가 보이게 찍으면 여러 장이 한 번에 인식됩니다.
- 초보자용 "배우기" 화면: 족보 순위, 팟 오즈·승률·아웃츠 개념, 헤즈업 전략 팁

## 카메라 인식의 한계 (정직하게)

자동 인식은 어디까지나 **추정값**이며, 다음을 전제로 설계했습니다.

1. **랭크(숫자·문자)**는 OCR로 추정하고, **무늬(♠♥♦♣)는 잉크 색(빨강/검정)으로만**
   후보를 좁혀 기본값을 채웁니다. 정확한 무늬는 사용자가 슬롯을 눌러 확정합니다.
2. 인식 결과는 항상 화면 슬롯에 채워진 뒤 **사용자가 확인·수정**합니다.
3. OCR 엔진은 첫 촬영 시 CDN에서 로드됩니다. 네트워크가 없거나 인식에 실패하면
   앱이 멈추지 않고 **수동 카드 선택 그리드로 자동 폴백**합니다.
4. 카드를 모서리까지 완전히 포갠 더미는 읽을 수 없습니다(전용 카드 검출 모델이
   필요한 별도 작업). "부채꼴로 겹쳐 펼치기"까지가 이 방식의 범위입니다.

인식 정확도를 위해 촬영 전 다음 전처리를 자동 적용합니다: 배경 잡음을 줄이도록
**중앙 밴드만 크롭**(화면의 노란 가이드 칸과 동일 영역) → **확대** → **그레이스케일
+ Otsu 이진화**로 글자 대비 강조 → **두 가지 PSM 모드로 인식 후 병합·중복 제거**.
그래도 장식체 J·Q·K나 무늬 구분이 약하면, 더 높은 정확도는 카드 전용 검출
모델(YOLO→ONNX 브라우저 추론)로 가는 것이 정석입니다.

**촬영 팁**: 노란 칸을 카드로 꽉 채우고(가까이), 밝은 곳에서, 배경은 어두운 단색으로,
숫자 모서리가 또렷하게 보이도록 찍으면 인식률이 크게 올라갑니다.

## 개발/실행

```bash
cd web
npm install
npm run dev      # 개발 서버
npm run test     # vitest 단위 테스트 (포커 엔진 15개)
npm run build    # dist/ 정적 파일 생성
npm run preview  # 빌드 결과 미리보기
```

이 저장소를 만든 환경에서 실제로 `npm run build`가 성공했고, vitest 15개 테스트가
모두 통과했으며, 헤드리스 브라우저로 전 화면을 렌더링해 동작을 확인했습니다.

## 배포

`npm run build`가 만드는 `dist/`는 완전한 정적 사이트라서 어떤 정적 호스팅에도
올릴 수 있습니다. 저장소 루트의 `vercel.json`이 Vercel에서 이 `web/` 폴더를
빌드하도록 설정되어 있습니다.

> 카메라 기능(`getUserMedia`)은 브라우저 보안 정책상 HTTPS(또는 localhost)에서만
> 동작합니다. Vercel 배포 URL은 HTTPS라 정상 작동합니다.
