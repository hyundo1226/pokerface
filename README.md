# 포커페이스 (PokerFace)

둘이서(헤즈업) 텍사스 홀덤을 할 때, 내 카드와 보드 카드를 입력하면
**승률 · 팟 오즈**를 계산해서 **콜 / 다이(폴드) / 체크 / 레이즈 / 올인** 중
무엇이 유리한지, 그리고 **왜** 그런지 이유까지 알려주는 안드로이드 앱입니다.
포커를 처음 접하는 사람도 개념(족보, 팟 오즈, 아웃츠, 승률)을 함께 배울 수 있도록
"배우기" 화면을 포함하고 있습니다.

## 구조

Gradle 멀티 모듈로 구성되어 있습니다.

- **`core`** — 순수 Kotlin/JVM 모듈. 안드로이드 의존성이 전혀 없어서
  이 저장소만으로도 `./gradlew :core:test`로 바로 빌드/테스트할 수 있습니다.
  - `Card`, `Suit`, `Rank`, `Deck` — 카드 모델
  - `HandEvaluator` — 5~7장 중 최고의 5장 족보를 판정 (하이카드~스트레이트 플러시)
  - `EquityCalculator` — 상대 홀카드를 모른다고 가정하고, 몬테카를로 시뮬레이션
    (리버는 전수 계산)으로 승/무/패 확률을 추정
  - `Advisor` — 승률과 팟 오즈(필요 승률)를 비교해 추천 액션과 한국어 설명을 생성
  - 15개의 단위 테스트로 검증되어 있습니다 (`core/src/test`).

- **`app`** — 안드로이드 앱 (Kotlin + Jetpack Compose).
  - `PokerViewModel` — 화면 상태(스트리트, 카드, 팟/베팅/스택, 계산 결과) 관리
  - `ui/screens` — 홈 / 카드·스트리트 설정 / 카메라 스캔 / 베팅 정보 입력 / 결과(추천) / 배우기
  - `camera/CameraController` — CameraX 미리보기 + 촬영
  - `camera/CardRecognizer` — 촬영한 카드 이미지에서 온디바이스 OCR(ML Kit)로
    랭크(A,2~10,J,Q,K)를 추정하고, 잉크 색상으로 빨강/검정을 판별

## 카메라 카드 인식에 대한 중요한 한계

플레잉 카드의 무늬(♠♥♦♣) 기호 자체를 이미지만으로 안정적으로 구분하는 것은
전용 데이터셋으로 학습한 모델 없이는 신뢰도가 낮습니다. 그래서 이 앱은:

1. **랭크(숫자/문자)**는 표준 OCR(ML Kit Text Recognition)로 추정하고,
2. **무늬는 색상(빨강/검정)만으로 후보를 2개로 좁힌 뒤** 기본값을 채워 넣습니다.
3. 카메라로 스캔한 결과는 항상 카드 설정 화면(`SetupScreen`)에 반영되며,
   **사용자가 각 카드를 눌러 최종 확인·수정**하도록 설계했습니다.

즉 카메라는 입력을 빠르게 해주는 "보조 도구"이고, 정확한 카드 값은
언제나 사람이 최종 확인합니다. 카메라 없이도 전체 화면에서 카드를 직접
탭해서 선택할 수 있습니다.

## 추천 로직 요약

- 필요 승률(팟 오즈) = 콜 금액 ÷ (팟 + 콜 금액)
- 예측 승률 ≥ 필요 승률이면 콜/레이즈, 아니면 폴드가 수학적으로 유리
- 여유분(예측 승률 − 필요 승률)이 클수록 레이즈 → 올인으로 추천 강도가 올라감
- 콜할 베팅이 없을 때(체크 가능 상황)는 승률이 아주 높으면 밸류 베팅(레이즈)을 추천

단, 상대의 블러프 성향이나 심리전은 고려하지 않는 **순수 수학 기반**의
단순화된 모델이며, 참고용 학습 도구로 설계되었습니다.

## 빌드 방법 (Android Studio)

1. 이 저장소를 Android Studio(최신 버전 권장)로 엽니다.
2. Gradle Sync를 실행하면 Android Studio가 필요한 Gradle Wrapper와
   Android Gradle Plugin, 의존성을 자동으로 내려받습니다.
   > 이 개발 환경(샌드박스)은 Google의 Maven 저장소(`dl.google.com`)와
   > Gradle 배포 서버로 나가는 네트워크가 차단되어 있어, 여기서는
   > `app` 모듈을 직접 빌드/실행해보지 못했습니다. `core` 모듈은
   > Maven Central만으로 빌드 가능해서 이 환경에서 직접 컴파일하고
   > 단위 테스트 15개를 모두 통과시켰습니다.
3. 실제 기기(또는 카메라를 지원하는 에뮬레이터)에서 실행해 카메라 권한을
   허용하면 카드 스캔 기능을 사용할 수 있습니다.

### core 모듈만 커맨드라인에서 테스트하기

```bash
./gradlew :core:test
```
(로컬에 Gradle Wrapper가 없다면 Android Studio에서 한 번 열었다가 다시
터미널에서 실행하거나, 시스템에 설치된 `gradle`로 실행하세요.)
